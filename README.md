## Production inference on ATOS

- Clone this repo to $PERM and install the venv there
- Auxiliary files (checkpoints, grib templates, etc.) should live in $HOME (or $HPCPERM)
- Files generated by the scripts should live in $SCRATCH
- Can't directly fetch from MARS on AG, so you need to use AC to create the datasets

1. Create virtual environments
   ```term
   # On AC cluster
   bash install.sh AC

   # On AG cluster
   bash install.sh AG
   ```

   The script also exports the following environment variables:
     For "static" auxiliary files
        - `CAERRA_MASKS_PATH`: path to the interpolation matrices (in NPZ format)
        - `CAERRA_CKPTS_PATH`: path to the inference checkpoints
        - `CAERRA_FORCINGS_PATH`: path to the high-resolution forcing datasets
        - `CAERRA_TEMPLATES_PATH`: path to the grib templates
        These four directories should contain one file per domain.

    For generated files
        - `CAERRA_OUTPUTS_PATH`: directory of the output grib files
        - `CAERRA_DATASETS_PATH`: directory of the input anemoi datasets

   Update your `.bashrc` file if you want to use different paths.

1. Prepare the input datasets (from AC)
   ```term
   bash prepare.sh <date>
   ```
   This produces cropped ERA5T datasets (one per region) for the given date.


1. Run the inference (from AG)
   ```term
   sbatch infer.sh <date>
   ```
