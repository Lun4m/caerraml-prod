## Production inference on ATOS

### Notes about the AG cluster
- Clone this repo to $PERM and install the venv there
- Auxiliary files (checkpoints, interpolation matrices, grib templates) should live in $HOME (or $HPCPERM)
- Inputs and outputs (generated by the scripts) live in $SCRATCH
- Can't fetch from MARS, so need to use AC instead
- TOOD: alternatively provide apptainer

1. Create virtual environments
   ```term
   # On AC cluster
   bash install.sh AC

   # On AG cluster
   bash install.sh AG
   ```

1. Prepare the input datasets (from AC)
   ```term
   bash prepare.sh <date>
   ```
   This produces cropped ERA5T datasets (one per region) for the given date.


1. Run the inference (from AG)
   ```term
   sbatch run.sh <date>
   ```
