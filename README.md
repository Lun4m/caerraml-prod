## Production inference on ATOS

### Notes about the AG cluster
- Clone this repo to $PERM and install the venv there
- Auxiliary files (checkpoints, interpolation matrices, grib templates) should live in $HOME (or $HPCPERM)
- Inputs and outputs (generated by the scripts) live in $SCRATCH
- TOOD: alternitively provide apptainer

1. Create virtual environment
   ```term
   bash scripts/install.sh
   ```

1. Prepare the input datasets
   ```term
   # or maybe sbatch?
   uv run caerra_tu_ml prepare 2026-08-01
   ```
   This produces a cropped ERA5T dataset per region for the given dates.


1. Run the inference 
   ```term
   # or maybe sbatch?
   uv run caerra_tu_ml run 2026-08-01
   ```
