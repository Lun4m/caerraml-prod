## Production inference

### Notes about the AG cluster
- Clone this repo to $PERM and install the venv there
- Auxiliary files (checkpoints, interpolation matrices, grib templates) should live in $HPCPERM or $HOME
- Inputs and outputs (generated by the scripts) should live in $SCRATCH



1. Install packages
   ```term
   bash scripts/install.sh
   ```

1. Prepare the input datasets
   ```term
   # or maybe sbatch?
   bash download.sh 2026-08-01 2026-08-02
   ```
   This produces one cropped ERA5T dataset per region between the given dates.


1. Run the inference 
   <!-- TODO: probably needs to be submitted by the ECFLOW suite -->
   ```term
   # or maybe sbatch?
   sbatch run.sh
   ```
