## Production inference on ATOS

### 1. Clone repo to $PERM.
Some notes:
- Auxiliary files (checkpoints, grib templates, etc.) should live in $HOME (or $HPCPERM)
- Files generated by the scripts should live in $SCRATCH
- Can't directly fetch from MARS on AG, so you need to use AC to create the datasets

### 2. Create virtual environments
```term
# On AC cluster
bash install.sh AC

# On AG cluster
bash install.sh AG
```

The script also exports the following environment variables:
<ul>
For "static" auxiliary files (these four directories should contain one file per domain)
<ul>
<li><code>CAERRA_MASKS_PATH</code>: path to the interpolation matrices (in NPZ format)</li>
<li><code>CAERRA_CKPTS_PATH</code>: path to the inference checkpoints</li>
<li><code>CAERRA_FORCINGS_PATH</code>: path to the high-resolution forcing datasets</li>
<li><code>CAERRA_TEMPLATES_PATH</code>: path to the grib templates</li>
</ul>
</ul>
<br>
<ul>
For generated files
<ul>
<li><code>CAERRA_OUTPUTS_PATH</code>: directory of the output grib files</li>
<li><code>CAERRA_DATASETS_PATH</code>: directory of the input anemoi datasets</li>
</ul>
</ul>

Update your `.bashrc` file if you want to use different paths.

### 3. Prepare the input datasets
From AC run
```term
bash prepare.sh <date>
```
This will generate cropped ERA5T datasets (one per region) for the given date.


### 4. Run the inference
From AG run
```term
sbatch infer.sh <date>
```
