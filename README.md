## Production inference on ATOS

### 1. Clone repo to $PERM.
Some notes:
- Auxiliary files (checkpoints, grib templates, etc.) should live in $HOME (or $HPCPERM)
- Files generated by the scripts should live in $SCRATCH
- Can't directly fetch from MARS on AG, so we need to use AC to create the datasets and archive the outputs

### 2. Create virtual environments
```term
# Needs to be run on both AC and AG clusters
./scripts/install.sh
```

The script also exports (to `$HOME/.caerrarc`) the following environment variables:
<ul>
For "static" auxiliary files (these four directories should contain one file per domain):
<ul>
<li><code>CAERRA_MASKS_PATH</code>: path to the interpolation matrices (in NPZ format)</li>
<li><code>CAERRA_CKPTS_PATH</code>: path to the inference checkpoints</li>
<li><code>CAERRA_FORCINGS_PATH</code>: path to the high-resolution forcing datasets</li>
<li><code>CAERRA_TEMPLATES_PATH</code>: path to the grib templates</li>
</ul>
</ul>
<br>
<ul>
For generated files:
<ul>
<li><code>CAERRA_OUTPUTS_PATH</code>: directory of the output grib files</li>
<li><code>CAERRA_DATASETS_PATH</code>: directory of the input anemoi datasets</li>
<li><code>CAERRA_LOGS</code>: where the log files for the different tasks will be saved</li>
</ul>
</ul>
<br>
<ul>
And finally:
<ul>
<li><code>CAERRA_WORK_DIR</code>: location of this repository on the filesystem
<li><code>CAERRA_PROD_DELAY</code>: production lag with respect to real time (in days)
</ul>
</ul>

Update your `.caerrarc` file if you want to use different paths.

### 3. Prepare the input datasets
```term
# Needs to run from the AC cluster
scripts/prepare.sh (date)
```

This will generate cropped ERA5-T datasets (one per region).
`date` is an optional parameter (with format `YYYY-mm-dd`) and it defaults to `$CAERRA_PROD_DELAY` days before the day you run the script.
The same convention is used in the scripts called in the next steps.

### 4. Run the inference
```term
# Needs to run from the AG cluster
# Serial (might need to update --time)
scripts/infer.sh (date)
# or parallellized over domains
scripts/parallel_infer.sh (date)
```

### 5. Archiving
```term
# Needs to run from the AC cluster
scripts/mars.sh (date)
```

### 6. CRON job
For simplicity we provide a crontab file that executes the whole pipeline. It can be loaded with 
```term
crontab cron/pipeline.jobs
```
